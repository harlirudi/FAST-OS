## Update Sesi Sebelumnya (App Links — commit `e97b1cd`)

**Masalah:** login Google di APK standalone tidak pernah kembali ke app (browser diblokir Chrome saat redirect ke custom scheme `facilityos://`; `openAuthSessionAsync` maupun `Linking` custom scheme sama-sama gagal di perangkat user).

**Solusi: Android App Links.**
- Redirect OAuth app → `https://web-chi-cyan-20.vercel.app/auth/callback` (https normal, tidak diblokir)
- Android intercept URL itu ke app karena: (1) `app.json` android.intentFilters autoVerify https://web-chi-cyan-20.vercel.app/auth/callback; (2) `web/public/.well-known/assetlinks.json` mendeklarasikan package `com.harlirudi.facilityos` + SHA-256 cert.
- AuthContext: standalone pakai redirect https, dev pakai `facilityos://` (__DEV__), timeout 60 detik, recovery session + exchange code saat cold start.

**PENTING — keystore EAS:**
- Fingerprint cert APK aktual: `66:69:20:D6:71:3F:CD:87:D6:EA:BF:27:61:9D:C6:8A:74:48:E1:1D:2B:BF:25:25:F1:BD:0D:3D:81:F4:76:D4` (EC, cert 264 byte).
- Keystore lokal (RSA, `mobile/facilityos-release.keystore`, 35BDBB8B) TIDAK terpakai oleh server build meski CLI bilang "Using local Android credentials" — akar masalah belum ketemu (dugaan: server pakai keystore ter-cache "Build Credentials W_ItbpQ31n").
- Build 1–3 (era remote credentials) cert BERBEDA tiap build (bug rotasi); sejak `credentialsSource: local` (build 4+) stabil di 666920D6.
- **WAJIB setiap build baru:** jalankan `python3 scripts/apk-signing-cert.py <apk>` dan cocokkan dengan assetlinks.json. Kalau berubah → update assetlinks.json + user wajib uninstall app lama.
- `credentials.json` (password keystore lokal) tetap gitignored; keystore ter-track git (EAS arsip build dari file ter-track).

## Update Sesi Sebelumnya (commit `be172ef`) — login Google deep link
- Gejala: tap Google di APK → browser terbuka → tidak kembali ke app → "Gagal login Google". Browser malah menampilkan sesi web lama ("Selamat datang...").
